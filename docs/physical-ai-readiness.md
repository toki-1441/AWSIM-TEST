## Completion gate

The evaluation-runner integration artifact
`Build/evaluations/goal-gate-provenance-smoke-001/goal-gate.json` was produced with a synthetic
checkpoint and a two-second episode limit. All three provenance checks passed: the normal suites
captured 216/203 frames, the holdout blackout withheld 202 frames, and the head-to-head holdout
captured 203 frames, with matching checkpoint hashes and suite seeds. Lap-time, blind-corner
safety and overtaking checks failed. This verifies the evaluation wiring only. That run used
the former erroneous +0.28 m opponent offset; the launcher now defaults to −0.28 m, with a
child-process regression covering both the default and an explicit positive override. Future
performance comparisons must use the corrected resolved scenario consistently. The separate
`Build/evaluations/signed-offset-smoke-001` player run completed all eight episodes and recorded
`lateralOffset=-0.28`, confirming that the signed value reaches the runtime configuration.

Do not mark the simulator goal complete until every evidence item above exists and the resulting
reports satisfy the thresholds agreed for the project. In particular, synthetic tests do not
substitute for real telemetry, trained-policy evaluation, or comparative safety results.
